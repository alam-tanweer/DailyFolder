Q: Given start=2, stop=35, and step=3 what is the size of the range (i.e. how
many integers does it contain)?
A: 11 = (35 - 2) // 3

Q: Given start=2, stop=35, and step=3 what is the value at index 7 in the 
range?
A: 23 = 2 + (3 * 7)

Q: Given any start<=stop and step>=1 derive a general formula for computing the 
value at any index i.

value = start + (step * index)

Q: Given any start<=stop and step>=1 derive a general formula for computing 
the size of the range.
A: Probable first attempt:
size = (start - stop) // step

Q: Will your formula work if the size of the range is/is not evenly divisible 
by the step?
A: Maybe, maybe not. Correct answer is to add 1 if size is NOT evenly divisble 
by step, e.g. 
   start=0, stop=100, step=3 should be ((100-0) // 3) + 1 = 34 (not 33)
