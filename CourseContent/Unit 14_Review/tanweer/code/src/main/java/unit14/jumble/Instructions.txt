Jumble Solver is a backtracking solution to solving jumble word puzzles.
For example:  Jumble = fhsi  Solved = fish.

The solver has a reference to a Dictionary object which provides the following
methods:
  isWord(string): returns true if the string is a word in the dictionary.
  isPrefix(): returns true if the string is a prefix for at least one word in
              the diectionary.

Complete the JumbleSolver backtracking methods in JumbleSolver.java
    getSuccessors()
    isValid()
    isGoal()
